this

10 sep 2026

Про this и контекст выполнения и ничего более.

this — это указатель.

this — это указатель на объект, который функция получает при вызове. Через this функция может получить доступ к свойствам и методам этого объекта. Всё это происходит внутри контекста выполнения функции, который включает в себя this, переменные и ссылку на внешнюю область видимости.

this — это не контекст выполнения, а просто указатель.

Глобальный контекст

Если написать this не внутри чего-либо, то он будет глобальным. Например, если написать прямо в консоли браузера:

snippet(1).js
1console.log(this); // window
2console.log(this === window); // true

this в этом случае ссылается на глобальный объект, в браузере это объект window, в Node.js это объект global. Независимо от строгого режима.

Объекты

В объектах this указывает непосредственно на объект, который стоит перед точкой во время вызова:

example.js
1const user = {
2  name: "dtsiki",
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6};
7
8user.sayHello(); // Привет, я dtsiki

Смотрим только на точку перед функцией в момент её запуска: this указывает на объект user, функция видит name, всё работает.

Обычные функции (все, которые не стрелочные)

У функций, объявленых через ключевое слово function, this в строгом режиме равен undefined, а в нестрогом — window:

example.js
1function doSomething() {
2  console.log(this);
3}
4
5function doSomethingStrict() {
6  'use strict';
7  console.log(this);
8}
9
10doSomething(); // window
11doSomethingStrict(); // undefined

Потому что обычные функции не умеют ходить дальше своей функции и брать контекст из лексического окружения. Но есть кто-то, кто так умеет.

Стрелочные функции

У стрелочных функций тоже нет контекста:

example.js
1const user = {
2  name: 'dtsiki',
3  sayHi: () => {
4     console.log(`Привет, я ${this.name}`);
5  }
6};
7
8user.sayHi(); // Привет, я undefined

Когда стрелочная функция пишется как свойство объекта, она создаётся в глобальном контексте (не внутри другой функции). При этом стрелочная функция не привязывается к объекту, в котором она лежит как свойство.

Вместо undefined может выводится пустая строка в браузере, так как контекст может ссылаться на объект window, у которого есть поле name со своим дефолтным значением — пустая строка "".

Но в отличии от обычных функций, стрелочные умеют брать контекст из родительского лексического окружения. Конечно же, зависит от того, где стрелочная функция написана. Как проявить суперспособность стрелочной функции:

example.js
1const user = {
2  name: 'dtsiki',
3  skills: ['JavaScript', 'TypeScript', 'React'],
4  showSkills() {
5    this.skills.forEach((skill) => {
6      console.log(`${this.name} знает ${skill}`);
7    });
8  }
9};
10
11user.showSkills();
Console
dtsiki знает JavaScript
dtsiki знает TypeScript
dtsiki знает React

Внутри forEach стрелочная функция, у которой нет контекста, но код тем не менее работает. Всё потому, что стрелочная функция смотрит наверх и берёт контекст из родительского окружения т.е. из метода showSkills.

Функции-конструкторы

Функция-конструктор в JavaScript — это обычная функция, которая создает и настраивает новые объекты с помощью ключевого слова new:

example.js
1function User(name) {
2  this.name = name;
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6}

Если функция вызывается как конструктор через new, то будет создан пустой объект и привязыван к this:

example.js
1function User(name) {
2  // Создаётся пустой объект this = {}
3  this.name = name; // Записывается в this name
4   sayHello() {
5    console.log(`Привет, я ${this.name}`);
6  }
7  // Функция возвращает этот объект this
8}
9
10const user = new User('dtsiki');
11user.sayHello(); // Привет, я dtsiki
12console.log(user.name); // dtsiki

Классы

Классы в JavaScript это синтаксический сахар над функциями-конструкторами. Поэтому в классах контекст ведет себя аналогично функциям-конструкторам:

example.js
1class User {
2  constructor(name) {
3    this.name = name;
4  }
5  sayHello() {
6    console.log(`Привет, я ${this.name}`);
7  }
8}
9
10const user = new User('dtsiki');
11user.sayHello(); // Привет, я dtsiki

Разница лишь в том, что контекст ссылается не на объект как таковой, а на конкретный экземпляр объекта, который был создан с помощью оператора new. Те же яйца, только в профиль.

Обработчики событий

В обработчиках событий this ссылается на DOM-элемент, на который непосредственно привязан этот обработчик:

example.js
1const button = document.querySelector("button");
2
3button.addEventListener("click", function (event) {
4  console.log(this, event); // <button>, click
5});

У стрелочных функций тут всё ещё контекста:

example.js
1const button = document.querySelector("button");
2
3button.addEventListener("click", (event) => {
4  console.log(this, event); // window, click
5});

Снова объекты

В JavaScript контекст легко потерять:

example.js
1const user = {
2  name: "dtsiki",
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6};
7
8const introduce = user.sayHello;
9introduce(); // Привет, я undefined

Куда делся контекст?

На (8) строчке в переменную introduce передаётся только ссылка на функцию sayHello. Объект user в этот момент остался где-то в стороне. На (9) строчке функция вызывается как изолированная функция, не привязанная к объекту user. Контекст теперь начинает указывать либо глобальный объект window, либо становится undefined в строгом режиме. А у глобального объекта нет свойства name. Вот и потеряли this.

Аналогичная ситуация произойдёт если метод объекта передать куда-то как колбэк. Например так:

example.js
1const user = {
2  name: "dtsiki",
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6};
7
8setTimeout(user.sayHello, 1000); // Привет, я undefined

Тут прописать user.sayHello() уже не прокатит — функция вызовется мгновенно.

Что можно сделать здесь в таких ситуация?

  1. Не забывать, что obj.func и obj.func() это совершенно разные вещи. Помним:

    • obj.func

      — обращение к свойству объекта, значением которого является сама функция или ссылка на неё. Сама функция при этом не вызывается

    • obj.func()

      — непосредственный вызов этой функции как метода объекта

  2. Использовать анонимную или стрелочную функцию

    Вызывать метод напрямую нельзя, поэтому отдаем функцию-пустышку, внутри которой вызываем метод правильно — через точку:

    example.js
    1const user = {
2  name: "dtsiki",
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6};
7
8setTimeout(() => user.sayHi(), 1000); // Привет, я dtsiki

  3. Вручную привязать объект к контексту

Принудительная привязка контекста

Вспомним пример где контекст потерялся:

example.js
1const user = {
2  name: "dtsiki",
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6};
7
8const introduce = user.sayHello;
9introduce(); // Привет, я undefined

Помимо вызова метода через точку user.sayHello(), этот код можно исправить тремя способами.

Можно вручную указать, что за контекст нужно принять такой-то конкретный объект. Для этого существуют три метода: call, apply и bind.

call и apply

Принимают контекст первым аргументом::

example.js
1const user = {
2  name: "dtsiki",
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6};
7
8const sayHello = user.sayHello;
9sayHello.call(user); // Привет, я dtsiki
10sayHello.apply(user); // Привет, я dtsiki

Обе функции вызываются сразу

Можно передать аргументы если они есть. Для call они передаются через запятую:

example.js
1function introduce(position, language) {
2  console.log(`Я ${this.name}, я ${position} и я люблю ${language}`);
3}
4
5const user = {
6  name: "dtsiki"
7};
8
9introduce.call(user, "фронтенд-разработчица", "JavaScript"); // Я dtsiki, я фронтенд-разработчица и я люблю JavaScript

Для apply в виде массива:

example.js
1function introduce(position, language) {
2  console.log(`Я ${this.name}, я ${position} и я люблю ${language}`);
3}
4
5const user = {
6  name: "dtsiki"
7};
8
9introduce.apply(user, ["фронтенд-разработчица", "JavaScript"]); // Я dtsiki, я фронтенд-разработчица и я люблю JavaScript

bind

Метод bind не вызывает функцию сразу, а создает новую функцию-обёртку, которая будет всегда помнить на что this теперь указывает:

example.js
1const user = {
2  name: "dtsiki",
3  sayHello() {
4    console.log(`Привет, я ${this.name}`);
5  }
6};
7
8const sayHello = user.sayHello.bind(user);
9sayHello(); // Привет, я dtsiki

Аргументы тоже можно передать, если они есть. Передаются через запятую после будущего контекста:

example.js
1function introduce(position, language) {
2  console.log(`Я ${this.name}, я ${position} и я люблю ${language}`);
3}
4
5const user = {
6  name: "dtsiki"
7};
8
9const introduceUser = introduce.bind(user, "фронтенд-разработчица", "JavaScript"); // "Я dtsiki, я фронтенд-разработчица и я люблю JavaScript"
10introduceUser();

Изменить контекст, который уже привязан с помощью bind, невозможно:

example.js
1const sayHello = user.sayHi.bind(user);
2sayHello.call({ name: 'Кто-то другой' }); // "Привет, я dtsiki"
3sayHello.apply({ name: 'Ещё кто-то' }); // "Привет, я dtsiki"

Если нужно, чтобы у функции менялся контекст, просто не используйте bind.

Резюмируем

Чтобы безошибочно понимать, чему равен this, смотрите только на точку перед функцией в момент её запуска:

  • Точка стоит после объекта: obj.doSomething()

    this равен объекту obj перед точкой

  • Точки нет: doSomething()

    this будет либо undefined в строгом режиме либо window

  • Точки нет, но есть конструктор-функции c new: new Something()

    this равен новому, только что созданному пустому объекту

  • Есть call, apply или bind

    this будет равен тому объекту, который вы передали в скобки
